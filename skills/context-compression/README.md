# context-compression

## Суть

Скилл поддерживает сжатую историческую память встреч: `meetings/README.md` с цепочками решений, устаревшими договорённостями, открытыми вопросами и якорными встречами.

## Файлы

- [SKILL.md](./SKILL.md) — основная инструкция.
- [meetings_readme.md](../../meta/templates/meetings_readme.md) — шаблон сжатой истории встреч.

## Следующий шаг

Использовать перед обработкой регулярных встреч, если старых саммари больше трёх или новая встреча ссылается на прошлые решения.
