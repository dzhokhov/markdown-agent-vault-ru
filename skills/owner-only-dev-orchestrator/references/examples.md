# Примеры

## Правильный вызов

«Исправь потерю настроек после обновления игры, сам проведи все технические шаги и покажи мне только доказанный итог».

Если поведение и продуктовый приоритет уже приняты, продуктовые роли не запускаются. Ожидается соразмерный технический маршрут, отдельные реализация и тестирование, архитектурный цикл только при изменении устройства системы, затем понятный пакет владельцу.

## Новый продукт

«Создай игру-бег с препятствиями, похожую по ощущению на Subway Surfers».

Ожидается: владелец продукта предлагает главную рамку и при необходимости один короткий бриф с рекомендуемыми ответами; продуктолог загружает игровой профиль, выбирает полный игровой цикл первого среза и явно откладывает магазин, коллекции и полировку; владелец продукта проверяет отклонение; только затем архитектор выбирает техническое устройство.

## Существенная возможность делового сервиса

«Добавь автоматическое формирование клиентского отчёта».

Если действующая рамка продукта уже определена, продуктолог предлагает один сквозной рабочий путь, отделяет обязательное от типовых функций категории и передаёт решение владельцу продукта на проверку. Полная рамка заново не создаётся.

## Неправильный вызов

«Кратко перескажи этот документ».

Это редакторская задача без изменения программной системы; полный цикл разработки не нужен.

Неправильно также запускать владельца продукта и продуктолога для замены библиотеки журналирования, если пользовательское поведение и продуктовая приёмка не меняются.

## Хороший итог

Жёлтый статус: сборка и автоматические тесты пройдены, но проверка обновления на целевом Android-устройстве недоступна. Выпуск удержан. Ближайший шаг команды — подготовить устройство и повторить один сценарий.

Если исход обязательной проверки неизвестен, хороший итог не ограничивается фразой «нужно проверить». Он сохраняет блокировку выпуска, прямо называет недостаток доказательств и передаёт точную фиксацию с конкретной проверкой независимому тестировщику.

## Провал

Зелёный статус только потому, что разработчик написал «всё проверил», без фиксации Git и результатов независимого тестировщика.
