# Формат файла саммари встречи

Файл создаётся на Шаге 4 pipeline в папке встреч контура (колонка «Встречи» карты контуров), имя: `YYYY-MM-DD_тема.md`. Все примеры ниже вымышленные: контур `acme-shop`, компания «Acme», люди «Анна П.» и «Виктор С.».

```yaml
---
id: meeting-YYYY-MM-DD-тема
type: meeting-summary
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases:
  - "Встреча по теме YYYY-MM-DD"
tags: [meeting, <контур>, <canonical-теги-из-TAGS.md>]
source_path: "<относительный путь от корня vault>"
freshness: seasonal
expires: <+3 месяца от даты встречи>
---
```

Тело файла — секции в этом порядке:

```markdown
# Встреча: <тема> — YYYY-MM-DD

## Суть
<1–2 предложения: о чём встреча, главный итог>

## Качество транскрипта
<источник, диаризация, потери, объём — обязательная заметка (Гейт 1)>

## Участники
- **Имя Фамилия** — роль (ссылка на карточку, если есть)

## Решения
<нумерованный список с пояснениями>

## Обещания
| Кто | Что | Срок | Куда ушло |
|-----|-----|------|-----------|
| Виктор С. | черновик ToR | 2026-04-18 | ссылка на строку в delegations/viktor-s.md |
| Владелец | подать декларацию | не названо | ссылка на personal/tasks.md |

## Действия (next steps)
<нумерованный список; для каждого — куда ушло (tasks.md / plan.md / delegations / personal)>

## Метрики
| Метрика | Значение | Тип | Куда ушло |
|---------|----------|-----|-----------|
| CPL | 2 $ | инвариант | context.md §Метрики проекта |
| CPA вчера | 5 $ | эпизод | ниже, `## Упомянуто вскользь #performance` |

## Стратегические развилки (если есть)
<описание развилок с аргументами сторон; ссылка в plan.md milestone или contingency>

## Упомянуто вскользь
- #onboarding: Анна П. вспомнила прошлогодний неудачный запуск обучающих роликов
- #pricing: Виктор С. упомянул желание пересмотреть тариф Pro
- #performance: вчера CPA скакнул до 5 $, сегодня откатилось

## Фактическая хронология по участникам
| Участник | Дата | Факт работы | Подтверждение | Источник | Уверенность |
|----------|------|-------------|---------------|----------|-------------|
| Имя | YYYY-MM-DD | сделал/настроил/проверил/получил X | короткая реплика | `source_path`[:таймкод] | высокая/неуверенно |

## Связи
- Контур: [ссылка на головную папку контура]
- Затронутые проекты: [ссылки]
- Классифицированные строки — см. колонки «Куда ушло» в «Обещаниях», «Действиях», «Метриках»
```

## Правила секций

- **`## Упомянуто вскользь`** — единственное допустимое место для эпизодических фактов. Теги — только из canonical registry [meta/TAGS.md §task-routing-tags](../../../meta/TAGS.md#task-routing-tags); новый тег сначала добавь в registry с одной строкой определения, потом используй. Grep-recall: `rg "#<тема>" <головная-папка-контура>/**/meetings/` поднимает все упоминания темы за секунды. Эпизодику клади сюда, вместо `context.md`.
- **`## Фактическая хронология по участникам`** — только для запросов вида «кто чем занимался / что сделал каждый / брифинг руководителю». Заполняется только прямыми отчётами говорящих о собственной работе (правила — [gates.md, Гейт 1](./gates.md)). Если участник только спорил, согласовывал, обсуждал или получил задачу на будущее — это не «занимался», сюда не попадает. Пустой раздел заполни строкой «по прямым отчётам в транскрипте не найдено».
- **Тест самодостаточности**: «Если LLM прочитает только этот файл — поймёт ли, о чём он?» Если нет — файл неполный.
