# Шаг 8. VERIFY — полный чеклист самопроверки

Пройди чеклист перед финальным подтверждением пользователя. Результат — отмеченный чеклист (или список невыполненных пунктов с причинами) в мини-отчёте.

## Контекст и линза

- [ ] Шаг 0.5 выполнен: загружен проектный контекст (context.md, plan.md, log.md, tasks.md) головной папки контура
- [ ] Для регулярной встречи или контура с 3+ встречами выполнен `context-compression` или зафиксировано, почему он не нужен
- [ ] История встреч старше скользящего окна не читалась целиком; использован `meetings/README.md` или пометка «сжатая история отсутствует»
- [ ] Модули предзагрузки из профиля агента выполнены по каждому участнику или в мини-отчёте стоит «модули: не объявлены»
- [ ] Люди не объединялись автоматически: совпадение без доказательства помечено `manual_decision_needed`, использован старый идентификатор как временная ссылка
- [ ] Чувствительные данные модулей не раскрыты и не записаны за пределы допустимого уровня; неподтверждённые записи не поданы как факт
- [ ] Линза разбора сформирована перед началом Шага 1 (EXTRACT)
- [ ] Если линза неполная (graceful degradation) — указано, какие компоненты отсутствуют

## Классификация и запись

- [ ] Все строки из Шага 1 прошли через decision tree Шага 3 (ни одна не потеряна)
- [ ] Каждая строка лежит в **одном** месте (без дублирования) — исключение: delegated-work блокер живёт одновременно в `plan.md §Blockers` и в `delegations/<slug>.md` с двусторонней ссылкой
- [ ] В `tasks.md` **не попали** делегирования, личные обязательства, milestones, размышления, **блокеры** (секции `Blocked` в tasks.md нет)
- [ ] В `context.md` **не попали** эпизодические факты
- [ ] `plan.md` обновлён, если были решения уровня milestone/scope/drift
- [ ] Все новые блокеры записаны в `plan.md §Blockers` как карточки `Bx` со всеми полями; статус затронутых milestone обновлён на `blocked on Bx`
- [ ] Для `delegated-work` блокеров parallel-строка в `delegations/<slug>.md` создана с обратной ссылкой на карточку в plan.md
- [ ] Разрешённые на встрече блокеры перемещены в `## Blockers — Resolved` (ritual: статус milestone снят, delegation в Done (7d), строка в log.md `✅ RESOLVED Bx`)
- [ ] Если изменялся подход/scope — в `log.md` добавлена строка дрейфа
- [ ] `log.md` обновлён коротко (3–10 строк, не дамп содержания встречи)
- [ ] `tasks.md` обновлён только агентскими execution-шагами
- [ ] Делегирования записаны в `delegations/<slug>.md` контура (папка — из карты контуров) со ссылкой на трекер и на встречу
- [ ] Личные обязательства записаны в `personal/tasks.md §Hard`
- [ ] Модуль журнала взаимодействий выполнен: строки на всех участников добавлены — или в мини-отчёте «модули: не объявлены»
- [ ] Проверено, нужно ли обновить `meetings/README.md` через `context-compression`; результат зафиксирован
- [ ] Эпизодические факты записаны в саммари под `## Упомянуто вскользь` с canonical-тегами из `meta/TAGS.md`
- [ ] Все новые теги (если добавлялись) внесены в `meta/TAGS.md §task-routing-tags` с одной строкой определения
- [ ] Люди автолинкованы или записаны в mention-log
- [ ] KNOWLEDGE FILTER применён ко всем фактам/метрикам: каждый элемент прошёл 4 эвристики, результат — ADD/UPDATE/EXTRACT-TO-KB/LINK или NOOP
- [ ] RECONCILE выполнен: кандидаты сверены с хранилищем, расхождения показаны пользователю
- [ ] Подтверждённые RECONCILE-изменения записаны в целевые файлы (context.md, база знаний, индексы)
- [ ] NOOP-элементы записаны в `## Упомянуто вскользь` с canonical-тегами
- [ ] Если создан файл саммари — он доступен через навигацию (README или context.md обновлён)
- [ ] Для контура с внешним трекером: командный протокол опубликован в вики трекера (Шаг 6j), оглавление раздела обновлено, «Источник:» задач по встрече ссылается на протокол; чувствительные слои в протокол не попали
- [ ] Ссылки между документами корректны (относительные пути проверены)
- [ ] Файл саммари проходит тест самодостаточности: «Если LLM прочитает только этот файл — поймёт ли, о чём он?»

## Полевые заметки (Шаг 7.5, встречи с внешними участниками)

- [ ] Если встреча с внешним участником — шаг извлечения атомарных наблюдений выполнен
- [ ] Полевые заметки (если созданы) имеют `confidence: single-source` во frontmatter
- [ ] Профиль организации по таксономии заполнен (если встреча с агентством/компанией и таксономия есть в базе знаний)
- [ ] Полевые заметки связаны с `context.md` проекта ссылкой
- [ ] Проведена перекрёстная проверка с предыдущими полевыми заметками (если они есть)

## Контракт вывода (7 гейтов)

- [ ] Гейт 1: есть таблица метрик, таблица обещаний (владелец + срок), маркер неуверенности, заметка о качестве транскрипта
- [ ] Если просили ретроспективу по участникам — есть `## Фактическая хронология по участникам`, и в ней только прямые отчёты говорящих о собственной работе; обсуждения и будущие назначения не смешаны с уже сделанным
- [ ] Гейт 2: присутствуют оба слоя — фактура и синтез «цепочки решений»
- [ ] Гейт 3: есть секция «уже в контуре vs новое» со ссылками
- [ ] Гейт 4: в контур ничего не записано без diff и подтверждения; нет файла `status: active` без согласования
- [ ] Гейт 5: финальный языковой чек пройден
- [ ] Гейт 6: решения о доле/деньгах, инциденты безопасности, внешние контакты сохранены и маршрутизированы
- [ ] Гейт 7: важные утверждения получили trust-классификацию (природа, основание, полномочия); конфликты не сглажены; изменения текущей картины зафиксированы
