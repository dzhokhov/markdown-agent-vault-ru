# Context

## Суть

Учебный контур показывает безопасную работу агента с репозиторием через манифест, правила, состояние проекта и заявку на изменение.

## Детали

- В контуре нет реальных закрытых данных.
- Основная ветка считается источником правды только после принятой заявки на изменение.
- Агент готовит изменения в ветке и объясняет их человеку простыми словами.
- Материалы встреч требуют классификации через `meeting_policy`.
- Сырые импорты и крупные файлы не попадают в репозиторий без отдельного решения.
