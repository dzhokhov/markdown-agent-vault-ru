# Plan

## Суть

План учебного контура показывает, как агент удерживает границы репозитория и готовит изменение через ревью.

## Goal

Показать минимальный безопасный контурный GitHub-репозиторий, который можно скопировать и адаптировать под реальную область работы.

## Non-goals

- Не моделировать закрытый слой.
- Не подключать внешние сервисы.
- Не хранить реальные персональные, финансовые, юридические или коммерчески чувствительные данные.

## Source of truth

- [repository-manifest.yml](./repository-manifest.yml) — границы контура.
- [AGENTS.md](./AGENTS.md) — правила поведения агента.
- Основная ветка GitHub после принятой заявки на изменение.

## Milestones

### M1 — Минимальный контур

**Acceptance:** есть `AGENTS.md`, `repository-manifest.yml`, `README.md`, `context.md`, `plan.md`, `tasks.md`, `log.md`, `CODEOWNERS`, шаблон заявки и безопасный материал.  
**Текущий статус:** done

### M2 — Проверка переносимости

**Acceptance:** локальная проверка проходит и показывает понятные ошибки при отсутствии манифеста.  
**Текущий статус:** in-progress

## Blockers

Пока нет открытых блокеров.

## Drift Guard

- Не добавлять реальные данные.
- Не расширять пример до полноценного рабочего контура.
- Не требовать от менеджера знания терминала.

## Contingency

Если пример становится слишком большим, оставить только корневые файлы и один материал.

## Следующий шаг

Запустить `validate_contour_repo.py` и убедиться, что пример проходит проверку.
