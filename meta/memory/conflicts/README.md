# Конфликты памяти

## Суть

Папка хранит конфликты уровня правил vault и сквозной долговременной памяти. Проектные конфликты можно хранить рядом с владельцем данных, если в проекте или контуре уже есть профильный слой решений, фактов или текущей картины.

Конфликт не сглаживается в сводке. Если два утверждения противоречат друг другу, агент создаёт или обновляет конфликт и связывает его с затронутыми карточками, текущей картиной или решением.

## Когда создавать конфликт

- Разные участники по-разному описали решение.
- Старый план конфликтует с новым.
- Текущая картина противоречит карточке решения.
- Встреча породила гипотезу, похожую на решение.
- Клиентское пожелание выглядит как обязательство, но не было принято командой.
- Источник без полномочий заявил изменение направления проекта.

## Активные конфликты

Пока нет.
