# Meetings: <контур>

## Суть

Канонический индекс и сжатая историческая память встреч. Файл нужен, чтобы агент не читал всю папку встреч целиком: последние встречи и якорные источники можно открывать полностью, более старые решения восстанавливаются по цепочкам ниже.

Это историческая навигация по встречам, а не текущая картина проекта или продукта. Если нужен ответ «что сейчас главное», он должен жить в отдельной текущей картине, объявленной в `README.md` или `context.md`.

Сжатая история встреч не является безусловной истиной. Для важных пунктов цепочек решений указывать тип утверждения, источник, основание, статус актуальности и уровень доверия. Слабые, спорные и давно не проверявшиеся пункты не переносятся в текущую картину как факты.
