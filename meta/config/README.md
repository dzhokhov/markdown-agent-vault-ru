# Настройки хранилища

Настройки отделяют личные сведения от общих инструкций. Первую настройку выполняет [vault-setup](../../skills/vault-setup/SKILL.md).

- [Карта контуров](./contours-map.md) — области работы и их папки.
- [Профиль агента](./agent-profile.md) — язык, обращение, дополнительные модули.
- [Профиль трекера](./tracker-profile.md) — необязательное подключение задач и вики.
- [Каноны письма](./writing-canons.md) — необязательные требования к текстам.
- `templates/` — исходные примеры настроек.

`status: template` означает ненастроенный пример. Первичная настройка меняет карту контуров и профиль агента; трекер и каноны письма можно настроить позже.
