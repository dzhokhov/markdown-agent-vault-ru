# Конфиг: профиль трекера

> **Это шаблон с вымышленным примером.** Статус `template` во frontmatter означает «настройка не проводилась»: агент не использует вымышленный пример как рабочие настройки. Если карта контуров и профиль агента уже активны, повторная первичная настройка не нужна: этот необязательный конфиг заполняется отдельно при первой необходимости. Если внешнего трекера нет — блоки остаются пустыми, скиллы пропускают шаги трекера с пометкой.

## Суть

По блоку на каждый внешний трекер: тип, адрес, источник ключа, коды проектов, особенности поиска, кэш и скрипты. Читают: `task-tracker-writer` (проверка дублей, создание задач), `meeting-processing` (снимок доски, вики протоколов), `vault-setup`. На блок ссылается колонка «Трекер» карты контуров (`meta/config/contours-map.md`).

## Блок `tracker-main` (пример)

### Подключение

- **Тип:** YouTrack.
- **Адрес:** `https://tracker.example.com`.
- **Ключ:** связка ключей системы (пример: сервис `tracker_api_token`) или переменная окружения `TRACKER_API_TOKEN` — указать один источник; сам ключ в файлы хранилища не записывать.
- **Дефолты создания задач:** исполнитель `ivanov`, `Type=Task`, `Priority=Normal`; связи между задачами — штатным механизмом трекера, не текстом.

### Коды проектов по контурам

Основной проект принадлежит контуру и в снимок доски грузится целиком; смежные — общие на несколько контуров, грузятся только с фильтром по людям контура.

| Контур | Основной проект | Смежные проекты |
|--------|-----------------|-----------------|
| acme-shop | `SHOP` | `OPS` (общие операционные задачи) |

### Особенности поиска (проверка дублей)

- По **одному ключевому слову на запрос**, 2–4 запроса; ограниченный набор полей, до 20 результатов на запрос.
- Несколько слов в одном запросе не склеивать, если трекер трактует их как «И» по целым словам — так теряются дубли.
- Составные слова усекать звёздочкой, если поиск это поддерживает: `видео*` находит «видеоинструкцию».

### Кэш и скрипты

- **Кэш снимков задач:** `00_inbox/tracker-issues/` — расходный слой чтения, не источник правды; пишет и чистит его только скрипт.
- **Скрипт снимка доски:** если используется — путь и параметры указать здесь; без скрипта скиллы работают по живому API или пропускают снимок с пометкой.
- **Логины сотрудников:** файл реестра людей контура с колонкой логина трекера, например `01_now/ops/acme-shop/team/persons.csv`.

### Вики

- **База статей:** `https://tracker.example.com/articles/`.
- Оглавления протоколов встреч по контурам — колонка «Вики протоколов» карты контуров.
