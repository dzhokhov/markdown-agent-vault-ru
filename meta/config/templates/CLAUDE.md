# CLAUDE.md — вход для агента

Прочитай `AGENTS.md` в корне хранилища: все правила работы — там.

Хранилище требует первичной настройки, если отсутствует `meta/config/contours-map.md` или `meta/config/agent-profile.md` либо один из этих двух файлов имеет `status: template`. Если оба имеют `status: active`, первичная настройка завершена. Шаблонные `tracker-profile.md` и `writing-canons.md` допустимы: их настраивают отдельно при необходимости.
Хранилище не настроено — предложи владельцу запустить скилл `vault-setup`
и не работай молча по вымышленным примерам из шаблонных конфигов.

Личные значения (контуры, трекер, каноны письма) живут в `meta/config/`.
В этот файл ничего личного не добавляй.
