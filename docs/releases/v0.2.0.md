# Release v0.2.0

Adds a fuller operating layer for the starter pack: agent-created projects, current memory, memory trust, compressed meeting history, and contour GitHub repository mode.

## Why This Release Matters

Before this release, the starter pack explained the folder structure and basic project files, but the user still had to rely on the agent's judgment for several hard parts:

- creating a complete project instead of a loose folder of files;
- keeping current state separate from old logs and meetings;
- knowing whether an old statement is a fact, a plan, a hypothesis, or a stale decision;
- handling long meeting history without rereading every old summary;
- moving one long-lived work contour into its own GitHub repository safely.

`v0.2.0` turns those practices into explicit rules, templates, skills, and validation.

## Changed

- `README.md`, `START_HERE.md`, `QUICKSTART.md`, and `ONBOARDING.md` now describe project creation, current memory, trust fields, and two usage modes: personal local vault and contour GitHub repository.
- `AGENTS.md` now tells agents to read `repository-manifest.yml` when it exists.
- `AGENTS.md` now routes new projects through `project-creator` and current-memory work through `vault-memory`.
- Write protocol, task routing, project templates, and meeting processing now cover current memory, trust fields, and agent-authored project plans.
- Write protocol and contour isolation rules now cover contour repositories.
- Pull request template now includes private data risk and human review fields.

## Also Included

- File-capable agent compatibility table.
- Claude Cowork skill sync notes and `skills/sync-cowork-skills.sh`.
- Intent reconstruction guidance for underspecified agent requests.
- Contour GitHub repository package.

## User Benefits

- Less manual setup: the agent can create a usable project instead of asking for a plan.
- Less context drift: project intent, boundaries, and quality criteria are written into `plan.md`.
- Safer memory: old logs and meetings are sources, not automatic truth.
- Better long-running work: current picture, memory ledger, and anti-memory make it harder to turn guesses into facts.
- Better meeting continuity: long histories can be compressed without losing reversals and stale decisions.
- Safer GitHub collaboration: contour repositories have boundaries, templates, checks, and review guidance.
